# Pyzogram (iOS)

Форк официального [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) с модом **Pyzogram**.

## Что добавлено

- В настройках появился раздел **Pyzogram** с переключателями:
  - **Режим призрака** — скрывает статус «в сети», набор текста и отметки о прочтении.
  - **Скрывать набор текста** — собеседники не видят, что вы печатаете.
  - **Показывать удалённые сообщения** — сохраняет текст удалённых собеседником сообщений.
- В самом низу вкладки Pyzogram — пункт **«Автор»**, открывающий экран с кнопками:
  - **GitHub** → https://github.com/L1ngDev
  - **Telegram** → https://t.me/logountw

Настройки сохраняются локально на устройстве.

## Сборка

Проект собирается через Bazel (`build-system/Make/Make.py`), только на macOS + Xcode.
Для сборки в GitHub Actions задайте в Secrets репозитория:

- `API_ID` и `API_HASH` — из https://my.telegram.org
- `TELEGRAM_CODESIGNING_GIT_PASSWORD` и `CODESIGNING_REPO` — для подписи (см. документацию Telegram-iOS)

IPA выгружается как artifact после успешной сборки.

> Примечание: поведенческие моды (призрак/анти-удаление) требуют глубокой интеграции
> с движком Telegram и дорабатываются итеративно при сборках на macOS.
